## 1. この講習会の位置づけ —— Solar-C (EUVST) に向けた実力づくり

**打ち上げ時に「すぐ解析できる人」を用意しておくのが目的。**
EIS はその練習台であって、目的ではない。

### EUVST の諸元（確認済み）

| | EUVST | Hinode/EIS |
|---|---|---|
| 波長帯 | **EUV 170–215 Å** + VUV 460–1220 Å | SW 171–212 Å / LW 245–291 Å |
| 温度被覆 | **2×10⁴ – 1.5×10⁷ K（シームレス）** | ~5×10⁵ – 5×10⁶ K（飛び飛び） |
| 空間分解能 | **0.4″** | ~2″ |
| 波長分解能 | ~5000 (EUV) / ~10000 (VUV) | ~4000 |
| カデンス | **1 秒** | 数十秒/ステップ |
| 実効面積 | **従来の 10–30 倍** | — |
| 視野 | 280″ × 280″ | — |
| 打ち上げ | 2028 年（Epsilon） | 2006 年 |

出典: [SOLAR-C 公式（NAOJ）](https://solar-c.nao.ac.jp/en/instruments.html)、
[Frontiers レビュー](https://www.frontiersin.org/journals/astronomy-and-space-sciences/articles/10.3389/fspas.2021.662790/full)

### ★ 決定的な事実: EUVST の EUV バンドは EIS の短波長帯とほぼ同じ

170–215 Å と 171–212 Å。**同じ輝線を撮る。**
Fe XI–XVI、Ca XIV–XVII、Si X、S X、Ar XIV —— この教材で扱う線は、
そのまま EUVST でも主力になる。原子データも、ブレンドの問題も、
密度診断ペアも、そっくり引き継がれる。

→ **「EIS で身につけたことは、ほぼそのまま EUVST で使える」**と言い切ってよい。
   これを講習会の冒頭で明示する。受講者の動機に直結する。

### 何が変わるか（＝EIS で今のうちに練習しておく意味）

- **データ量が桁違いに増える。** 0.4″・1 秒・実効面積 10–30 倍。
  「1 本ずつ手で確認する」やり方が通用しなくなる。
  → **処理を自動化し、結果の妥当性を機械的に検算する習慣**が要る。
- **温度被覆がシームレスになる。** DEM の逆問題としての性質が良くなる。
  ただし ill-posed であること自体は変わらない。**手法依存性の理解は必須のまま。**
- **速度・線幅が主戦場になる。** 0.4″/1 秒なら、これまで見えなかった
  流れと乱れが見える。**強度だけ出せても足りない。**（→ 目標 B の重み付けを上げる）

## 3. 何が Solar-C に転移し、何が EIS 固有か

教材の中で**明示的にラベルを付ける**。受講者が「これは今だけの話か、ずっと使う話か」を
区別できるようにするため。

| 転移する（EUVST でも必要） | EIS 固有（知っていれば十分） |
|---|---|
| スリット走査＝ラスターは同時刻でない | EIS のラスターは 1 時間かかる（EUVST は速い） |
| ガウシアン＋背景でのフィット、成分の取り違え | eispac のテンプレート機構の細部 |
| **波長の基準をどう決めるか**（絶対基準が無い） | EIS の軌道変動の具体的な補正手順 |
| **装置幅を引かないと非熱的幅は出ない** | EIS の装置幅がスリット位置で 22% 変わること |
| 欠損値・不良画素の扱い | 欠損が「大きな負のフラグ値」であること |
| ブレンドの分離（原子データで拘束する） | Ca XVII 192.858 という具体例 |
| G(T)・電離平衡・組成の不確かさ | CHIANTI の実装差 3% |
| DEM は ill-posed、手法依存 | demregpy / PINTofALE の作法 |
| **絶対較正は 20% 程度ずれるものだという感覚** | EIS の打ち上げ後劣化 |

## 4. 構成案

**原則**: 各章は**問いで始め、手を動かし、最後に答え合わせる**。
「私が踏んだ罠」ではなく「あなたが必ず踏む罠」だけを、**先に踏ませてから**直す。

### 第 0 部: なぜこれをやるのか（15 分・講義）

- Solar-C EUVST は EIS と同じ波長帯を、10–30 倍の感度で撮る
- 今日やることは、そのまま 2028 年に使う
- 題材: 活動領域コアの高温プラズマ。**加熱は高頻度か低頻度か**という未解決問題
- **最初に完成品（EM 分布と α）を見せる。** 以降の全作業がここに向かうと分かる

### 第 1 部: 測る（目標 A）

問い: **「この輝線の明るさはいくらか」を、どうやって数字にするか**

1. スペクトルを 1 本見る → 山の面積が強度
2. フィットしてみる → **成分を取り違える**（Fe XIII を頼んで Fe XII が返る）
3. 箱で平均してからフィット → **黒い縞**（欠損値）
4. 誤差をどう入れるか（統計誤差だけでは足りない）

→ 演習: 指定された輝線を各自フィットして強度を出す

### 第 2 部: 動きと乱れを測る（目標 B）★新規

問い: **同じフィットから、速度と線幅も出るはず。そのまま信じてよいか**

1. 速度マップを出してみる → **一面が数十 km/s ずれている**
   - `wave_corr` を見る: 補正量は **±0.017 Å = 195 Å で 53 km/s**（実測）
   - その内訳: 軌道変動 `wave_corr_t`（時間）と スリット傾き `wave_corr_tilt`（位置）
   - **絶対波長基準が無い**ので、視野内の平均などをゼロ点に取るしかない
   - → EUVST でも同じ問題が出る。**「速度ゼロ」を自分で定義する**という感覚を持たせる
2. 線幅から非熱的速度を出す
   - σ_obs² = σ_inst² + σ_th² + σ_nonth²
   - **装置幅はスリット位置で 0.0562 → 0.0685 Å と 22% 変わる**（実測）
   - 定数で引くと、**偽の空間構造**が非熱的幅マップに出る（これを見せる）
   - 熱幅はイオン質量と温度から。**温度は仮定**（形成温度）→ 仮定の依存性を見る

→ 演習: 速度と非熱的幅のマップを作り、moss と inter-moss で値を比べる

### 第 3 部: どこを測るか（目標 A/B の応用）

問い: **同じラスターでも、場所を変えたら答えは変わるのか**

- inter-moss とは何か、なぜそこを選ぶのか
- **箱を受講者ごとに分担**して median・傾き・15% 以内の本数を持ち寄る
- → 「どこを測るかを決めるのが解析の本体」を、自分の数字で理解する

### 第 4 部: 論文と答え合わせ（客観的な正解がある）

- Warren+2012 Table 2 と 1 行ずつ照合
- 合わない線の切り分け手順（**独立な 2 つ目の測定を持ってくる**）

### 第 5 部: 温度分布にする（目標 C）

問い: **輝線ごとに違う絵に見えた。温度ごとの量を復元できるか**

- G(T) と EM loci（解く前に答えの見当をつける）
- DEM は ill-posed。特異値で見る
- 手法・事前分布で α が動く。**ピーク温度は動かない**
- → 演習: 自分の領域で EM ピークと α を出し、**系統誤差を 1 つ挙げる**（＝合格判定）

### 付録（当日はやらない。自分の研究で使うときに読む）

- Ca XVII のブレンド分離（自作テンプレート、`tied` の実際）
- 較正バージョンによる違い
- eispac の実装上の落とし穴（`scale_guess` と `fixed`、HDF5 での `tied` 切り詰め、
  `measrmnt` キー、`dsun` の差による submap の 1 画素ずれ）
- AIA Fe XVIII の応答関数を自分で作る
- 他の活動領域・15 領域の統計

## 6. 「押すだけ」にしない仕掛け

1. **箱の分担**（第 3 部）。他人と違う数字が出るので、押すだけでは成立しない
2. **穴あきセル**。要所を `# TODO` にして 1–2 行書かせる。答えは別ノート
3. **予想を書かせてから実行**。外れた人ほど記憶に残る
4. **罠は先に踏ませる**。壊れた結果を見せてから原因を考えさせる
5. **最終課題**（第 5 部）。系統誤差を 1 つ挙げて根拠を示す
