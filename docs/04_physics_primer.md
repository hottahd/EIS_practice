**この文書の要点を先に 3 つ:**

1. コロナは**光学的に薄い**ので、輻射輸送を解く必要がない。
   視線に沿った**単純な足し算**になる。光球とは真逆で、ここが一番易しい。
2. その代わり、**輝線ごとに「効く温度」が違う**。これを使って温度分布を測る。
   G(T) がその「効く温度」を表す関数。
3. 温度分布を求めるのは**第一種 Fredholm 積分方程式の逆問題**で、
   本質的に ill-posed。だから「解いた」と言うときは
   **何を仮定したか**を必ずセットで言う必要がある。

## 1. なぜコロナは光球と正反対なのか

### 光球（あなたが知っている世界）

- 密度が高い → 衝突が頻繁 → **LTE**（局所熱力学平衡）が良い近似
- 連続吸収が効く → **τ ~ 1** の層を見ている
- ソース関数 ≈ プランク関数
- 「どの深さを見ているか」を決めるのが仕事（輻射輸送方程式を解く）

### コロナ

- 密度が桁違いに低い（n_e ~ 10⁹ cm⁻³ vs 光球 ~10¹⁷ cm⁻³）
- EUV 輝線に対して **τ << 1**（光学的に薄い）
- → **輻射輸送を解かない。** 視線上の放射を全部足すだけ。

  ```
  I_λ = (1/4π) ∫ ε_λ ds        ε_λ は単位体積あたりの放射 [erg cm⁻³ s⁻¹]
  ```

  1/4π は「全立体角に等方的に出る」ことから来る（sr⁻¹ に直すため）。

- **LTE ではない。** では何が成り立つか → **コロナ近似**（次節）

### ★ 理論屋が最初に納得すべきこと

光球では「見ている場所」が問題だったが、コロナでは**視線上の全部が見えている**。
だから逆に「視線上のどこに何度のプラズマがあるか」が分からない。
**その情報を、輝線ごとの温度感度の違いから引き出すのが DEM 解析**である。

## 2. コロナ近似 —— なぜ ε ∝ n_e n_H になるのか

コロナの EUV 輝線は次の過程で出る:

1. イオンは基底準位にいる（密度が低いので励起準位に長く留まれない）
2. **電子衝突**で上準位 j に励起される。レート ∝ n_e × n_ion
3. **自発放射**で下準位 i に落ちる。レート = A_ji（アインシュタイン係数）

密度が低いので (2) の励起がボトルネックで、上がったらほぼ確実に光を出す。
したがって

```
ε_λ = n_j A_ji hν
    ≈ (n_e n_ion C_exc) × hν          ← 定常状態で n_j A_ji = n_e n_ion C_exc
```

ここで n_ion を分解する:

```
n_ion = (n_ion/n_elem) × (n_elem/n_H) × (n_H/n_e) × n_e
        └── 電離平衡 ──┘  └── 組成 ──┘  └─ 0.83 ─┘
```

まとめると

```
ε_λ = G_λ(T) n_e n_H              [erg cm⁻³ s⁻¹]

G_λ(T) = A(Z) × f_ion(T) × (n_H/n_e) × (hc/λ)(n_j/n_ion)A_ji / n_e
         組成    電離平衡              励起（準位占有数）
```

**この G(T) が「寄与関数」**。単位は erg cm³ s⁻¹。

### 実際の数値（今日計算したもの）

`scripts/idl/09_gofnt.pro` / `scripts/gofnt_fiasco.py` の出力:

| 輝線 | G のピーク値 [erg cm³ s⁻¹] | ピーク温度 log T |
|---|---:|---:|
| Si VII 275.368 | 4.4×10⁻²⁴ | 5.80 |
| Fe XII 195.119 | 1.4×10⁻²³ | 6.20 |
| Fe XV 284.160 | 2.2×10⁻²³ | 6.35 |
| Ca XVII 192.858 | 3.3×10⁻²⁵ | 6.80 |

→ **輝線ごとに効く温度が違う**（log T 5.8 から 6.8 まで）。これが武器。

### なぜ G(T) は温度の「狭い」関数なのか

主な理由は **電離平衡 f_ion(T)** が狭いから。

- 温度が低いとそのイオンはまだ電離していない（もっと低い電離段にいる）
- 温度が高いとさらに電離してしまう（もっと高い電離段になる）
- → 各イオンは **log T で 0.2–0.3 dex 程度の幅**でしか存在しない

たとえば Fe XVIII の存在比は log T = 6.90 でピークになり、
そこでも全鉄の **32%** しかない（今日 CHIANTI で確認した値）。

**注意**: これは「電離平衡が成り立っている」という仮定。
急激な加熱・冷却があると電離が追いつかず（非平衡電離）、この前提は崩れる。
論文もこの仮定の上に立っている。

### 密度に依存する線としない線

上の式で「励起」の部分は、厳密にはイオン内の全準位の占有数を解く必要がある。
基底準位からの単純な励起なら密度に依らないが、
**準安定準位**（放射で落ちにくい準位）が絡むと、密度が高いほどそこに溜まり、
そこからの励起が効くようになる。→ **密度診断線**。

今日の 3 実装比較（CHIANTI IDL / fiasco / ChiantiPy）で、
**実装間の差が大きい線と小さい線がきれいに分かれた**:

| 実装間の差が大きい | | 差がほぼ無い | |
|---|---|---|---|
| Fe XIII 202.044 | 11% | Fe IX 197.862 | 0.03% |
| Fe XIII 203.826 | 10% | Ca XVI 208.604 | 0.05% |
| Fe XIV 264.787 | 3.4% | Ca XIV 193.874 | 0.16% |
| Si X 258.375 | 2.9% | Fe XV 284.160 | 0.22% |

**差が大きい側が密度敏感線。** 準安定準位の扱いがコードごとに違うため。
これは「原子データの不確かさ」を実測した形になっている。

## 3. DEM とは何か

### 定義

視線積分を温度でパラメータ化し直す:

```
I_λ = (1/4π) ∫ G_λ(T) n_e n_H ds
    = (1/4π) ∫ G_λ(T) ξ(T) dT

ξ(T) ≡ n_e n_H (ds/dT)         [cm⁻⁵ K⁻¹]
```

**ξ(T) が DEM（Differential Emission Measure）。**

意味: 「温度 T から T+dT の間にあるプラズマが、視線上にどれだけあるか」を
n_e n_H で重み付けして数えたもの。ds/dT は「その温度範囲が視線上で何 cm を
占めるか」。

- 視線上の温度構造が**どんな形でも**（ループが何本あっても、
  温度が単調でなくても）定義できる。**幾何を仮定しない**のが利点。
- 逆に言えば、DEM から幾何は分からない。

### EM（Emission Measure）との関係

論文は DEM そのものではなく **EM 分布 ξ(T)dT** を描く（論文 Eq. 3）。
温度ビンごとの「そのビンにある放射量」で、単位は cm⁻⁵。

**★ ここは実装で最も間違えやすい。** コードによって DEM の単位が違う:

| | DEM の単位 | ビンあたりの EM |
|---|---|---|
| PINTofALE (MCMC) | cm⁻⁵ **/ logK** | DEM × ΔlogT |
| demregpy | cm⁻⁵ **/ K** | DEM × ΔT = DEM × T ln10 ΔlogT |

**実際に私はここを間違えて、傾き α を 3.30 と誤って報告した**（正しくは 2.30）。
T を余計に掛けると傾きがちょうど +1 ずれる。

### EM loci —— DEM を解く前に必ず描く図

輝線 λ の観測強度 I_λ に対し、
「**もし視線上のプラズマが全部温度 T にあったとしたら**、
必要な EM はいくらか」を計算する:

```
EM_loci,λ(T) = 4π I_λ / G_λ(T)
```

- これは各温度における **EM の上限**。真の EM 分布は必ずこの下にある。
- 全輝線の EM loci 曲線を重ねると、**下側の包絡線**が DEM の目安になる。
- **等温プラズマなら全曲線が 1 点で交わる。** 交わらなければ多温度。

DEM を解く前にこれを描くと、「4 MK 付近にピークがある」がもう見えてくる。
逆問題を解く前に答えの見当がつくので、**解が変になったときの検算に使える**。

### なぜ逆問題が難しいのか

```
I_λ = (1/4π) ∫ G_λ(T) ξ(T) dT
```

これは ξ について**第一種 Fredholm 積分方程式**。
既知は I_λ（22 個の数）と G_λ(T)（既知の関数）、未知は ξ(T)（連続関数）。

**ill-posed である理由:**

1. **G_λ(T) が滑らかで幅広い。** log T で 0.2–0.3 dex の幅がある。
   → ξ(T) に細かい構造を入れても、G との積分で均されて I_λ に現れない。
   → **I_λ から ξ の細かい構造は復元できない。**
2. 逆に言えば、I_λ をわずかに変えるだけで ξ の細かい構造は激しく変わる。
   → **観測誤差が解に増幅される。**

数学的には、積分作用素の特異値が急速に 0 に近づくため、
逆作用素が非有界になる。

### 2 つの解き方

**(a) 正則化 (demregpy, Hannah & Kontar 2012)**

「滑らかさ」を罰則項として加え、
`|I_obs − I_model|² + λ|L ξ|²` を最小化する。λ が正則化パラメータ。

- 長所: 速い、決定的（同じ入力なら同じ出力）、誤差も出る
- 短所: **λ の選び方で答えが変わる**。滑らかにしすぎるとピークが均される

**(b) MCMC (PINTofALE, Kashyap & Drake 1998)**

ξ(T) の各温度ビンをパラメータとして、Metropolis 法で事後分布をサンプルする。

- 長所: 誤差が**分布として**出る。上限値（検出限界）も扱える
- 短所: 遅い、平滑化スケールの設定が要る、初期値依存

### 今日実際に比べた結果

同じ観測強度・同じ G(T) で解いた（`figures/dem_compare.png`）:

| 手法 | χ²ᵣ | EM ピーク | α (6.0–6.6) |
|---|---:|---|---:|
| demregpy 既定 | 5.08 | 4.5 MK | 1.53 |
| demregpy (MCMC を事前分布に) | 2.22 | **3.98 MK** | 2.13 |
| MCMC_DEM | — | **3.98 MK** | 2.30 |
| 論文 | — | 「4 MK 付近」 | 2.9 |

**教訓:**
- **ピーク温度 4 MK はどの手法でも動かない** → 頑健な結論
- **傾き α は 1.53–2.30 と手法依存** → 慎重に扱うべき量
- demregpy に MCMC の解を事前分布として与えると χ² が 5.08 → 2.22 に改善
  → **答えが事前分布に強く依存している証拠**

論文自身もこう書いている:
> "It is also clear, however, that the detailed structure of the EM distributions
> is much more difficult to determine with confidence."

## 4. なぜ 4 MK が重要なのか —— 物理の問い

ここが論文の科学的な主張。

### 問い: コロナはどう加熱されているか

**Parker のナノフレア説**: 磁力線が対流でランダムに足を揺すられ、
ねじれが溜まり、磁気リコネクションで**間欠的に**エネルギーを放出する。

このとき、1 本のループは
「加熱 → 高温になる → 冷える → また加熱」を繰り返す。

### 加熱の頻度が EM 分布の形を決める

ループの冷却時間 τ_cool と、加熱イベントの間隔 τ_heat を比べる。

**低頻度加熱（τ_heat >> τ_cool）= ナノフレア説の描像**
- ループは加熱後、次の加熱まで**十分に冷える**
- 視線上には「今冷えている途中」のプラズマが各温度にたくさんある
- → **EM 分布は幅広く、傾き α は緩い**
- 流体シミュレーションでは α ≈ 2.0–2.3 が最も急な部類
  （論文 p.11 が引く Mulu-Moore et al. 2011）

**高頻度加熱（τ_heat << τ_cool）= ほぼ定常**
- ループは冷える暇がなく、いつも高温に保たれる
- 視線上のプラズマは狭い温度範囲に集中する
- → **EM 分布は鋭くピークを持ち、α は急**

### 論文の主張

観測された α ≈ 2.9–3.4 は、ナノフレア・シミュレーションの上限 2.3 より**急**。
→ 「活動領域コアの高温プラズマは**熱平衡に近い**」
→ 「加熱は**高頻度**でなければならない」
→ Parker のナノフレア描像（低頻度）への挑戦

さらに論文は、**磁束が大きい領域ほど EM が鋭くピークを持つ**（＝高頻度加熱）
という傾向を 15 領域で示した。

### ★ 我々の結果が持つ意味（正直に）

我々が測った α = **2.30** は、**ナノフレア・シミュレーションの上限とちょうど同じ**。
論文の 2.9 は明確に上回るが、我々の値は境界上にある。

つまり **α の 0.6 の差が、科学的な結論を左右する**。
そして今日の検証で分かったとおり、α は

- 箱の位置（0.83–0.95 の範囲で median が動く）
- DEM の手法（1.53–2.30）
- 温度ビンの取り方

に敏感である。**「α が急だからナノフレアは否定される」と言うには、
これらの系統誤差を全部押さえる必要がある。** これは論文への批判ではなく、
この種の測定の難しさそのもの。**講習会で一番伝えるべきはここ。**

## 5. 観測データの実際

### EIS はどういう装置か

- **スリット分光器**。細長いスリット（幅 1″ または 2″、長さ 512″）を
  太陽に当て、その 1 次元の像を波長分散させて CCD に落とす。
- 1 回の露出で得られるのは **(スリット方向 512 画素) × (波長方向)** の 2 次元。
- **2 次元の像がほしければスリットを横に振る** → これが**ラスター**。
  region 7 は 60 ステップ、1 ステップ約 60 秒 → **全体で約 62 分**かかる。

**★ 理論屋が注意すべき点**: 「画像」に見えるが、**同時刻ではない**。
左端と右端で 1 時間離れている。時間変動する現象には使えない。

- 波長範囲は **171–212 Å（短波長 SW）と 245–291 Å（長波長 LW）** の 2 バンド。
- 全波長を毎回落とすとテレメトリが足りないので、
  **必要な輝線の周りだけを「スペクトルウィンドウ」として切り出して降ろす**。
  region 7 の観測には 25 個のウィンドウがある。
  → **どの輝線が観測されているかは、観測プログラムの設計時に決まっている。**
    Ca XIV–XVII が入っている観測は貴重（3 MK 以上を拘束できる）。

### level-0 → level-1（較正）

- **level-0**: CCD の生データ（DN = デジタル値）
- **level-1**: 較正済み（erg cm⁻² s⁻¹ sr⁻¹ Å⁻¹）

やっていること:
1. CCD のペデスタル（オフセット）と暗電流を引く
2. 不良画素（ホット/ウォーム/ダスティ）を特定して除く
3. 宇宙線ヒット（スパイク）を除く
4. **実効面積で割って物理単位にする**

**★ 較正の劣化**: EIS は 2006 年打ち上げ。有機物の付着などで感度が落ちる。
しかも**波長によって落ち方が違う**。
打ち上げ後較正が 2 つ提案されている（Del Zanna 2013、Warren+2014）が、
**両者は食い違っている**。今日の検証では、どちらを当てても論文の値と
整合しなかった（`work/eis_calcurve_20110702.txt`）。

### moss と inter-moss —— なぜその場所を選ぶのか

**moss（モス）**: 高温ループの**足元**。上から熱伝導で熱が降りてきて、
遷移層あたり（~1 MK）が明るく光る。171 Å や Si VII で「まだら模様」に見える。

**inter-moss**: moss と moss の間、つまり**ループの脚ではなく上部を見ている**場所。

**なぜ inter-moss を選ぶか:**
- moss を含むと、視線上に「足元の 1 MK」と「ループ上部の 4 MK」が混ざる
- 足元は熱伝導・彩層蒸発が絡む複雑な物理
- **ループ上部（コロナ本体）の温度分布だけを見たい** → moss を避ける

論文の言い方:
> "the inter-moss region, that is, the region between the loop footpoints where
> we are measuring the properties near the loop apex"

**★ ここが解析で最も主観的な部分。** 論文は目視で箱を選んでおり、座標を書いていない。
今日 Figure から座標を復元したが（`scripts/extract_paper_boxes.py`）、
箱を動かすと median ratio が 0.83–0.95 の範囲で動く。

### AIA の Fe XVIII —— なぜ必要か

EIS で観測できる最高温の強い輝線は **Ca XVII 192.858（~5 MK）**。
それより上を拘束するものが無いと、EM 分布の高温側の裾が決まらない。

そこで **AIA 94 Å の Fe XVIII 93.932 Å（~7 MK）** を使う。
ただし 94 Å チャンネルには低温の線も入っているので、
**171 Å と 193 Å から「低温成分」を経験的に見積もって引く**（論文 Appendix）。

今日の作業で:
- 論文の式 (A1) の**指数が誤植**であることを実データで確定した
- **Fe XVIII だけの応答関数**を作った（公式応答は低温線を含むので使えない）
  → R(T) ピーク 2.73×10⁻²⁷ DN cm⁵ s⁻¹ pix⁻¹ at log T 6.90
- この拘束を入れないと、log T > 6.9 に EM が漏れて傾き β が出鱈目になる
  （PINTofALE のドキュメントが "toothpaste tube effect" と呼ぶ現象）
